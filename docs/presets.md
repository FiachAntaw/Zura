# Z-Suite → Cura preset mapping

Generated by `tools/gen_presets.py` from Z-Suite 3.7.0's own `Configuration` objects (extracted for every valid M200 Plus material × layer height × quality combination, `plugins/ZortraxM/zsuite_profiles/`).

Quality types: `z10`, `z15`, `z20`, `z30` (High) and `*_draft` (Draft). Only combinations Z-Suite offers are generated.

## Where each setting lives

`tools/gen_presets.py` puts every setting in exactly one Cura container, chosen by what it depends on across all 102 Z-Suite profiles:

| Container | File | Holds |
| --- | --- | --- |
| Machine definition | `definitions/zortrax_m200_plus.def.json` (keys listed in `metadata.zura_generated_overrides`) | Settings that are the same for every filament and layer height: raft structure, wall count, infill pattern and density, travel speed, Z hop on, combing, seam, bridges. Initial/final print temperature follow the print temperature. |
| Material | `materials/zortrax_*.xml.fdm_material` | Filament-only settings: print and bed temperature, retraction, cooling, raft base thickness, Z-hop height, plus the filament's usual value for settings that also vary a little with layer height (wall flow, raft gap, first-layer speeds, support spacing). |
| Global quality | `quality/zortrax_m200_plus/zortrax_m200_plus_global_*.inst.cfg` | Layer-height settings shared by all filaments: layer height, top/bottom layers, infill line width, raft layer counts and margin, support Z gap and angle, and the usual speeds for that layer height. |
| Material quality | `quality/zortrax_m200_plus/zortrax_m200_plus_zortrax_*_z*.inst.cfg` | Only the exceptions where a filament at a given layer height differs from the material or global value (about 4–5 values per profile). |

Cura resolves them in the order material quality > material > global quality > definition. `tests/cura_e2e/run_cura_dump.sh` resolves every setting for every material × quality in headless Cura; the split was checked to give identical per-extruder values to the earlier flat profiles for all 85 combinations, and an identical toolpath for the test cube. After adding Z-SEMIFLEX (0.14/0.19/0.29 mm) and the 0.30 mm Normal profiles, all 102 combinations were re-checked against the Z-Suite values.

## Not portable (CuraEngine has no equivalent)
- First-layer feeds (`FL_*Feed`) and raft feeds: not mapped (inconsistent across layer heights). Top/bottom skin needs no change: Z-Suite's lower feed is offset by tighter line spacing.
- Contour entrance/exit moves, contour cutting (`ContourEntrance*`, `CutContour*`).
- Z-Suite's "visible/invisible" infill distinction and small-area infill (`VTS_*`, `VBS_*`).
- Support pyramid / lite / hybrid modes (`SB_Pyramid*`, `SUPPORT_LITE`).
- Linear advance K (`LinearAdvanceKFactor*`): passed through to the printer by the writer instead.
- Polygon slowdown (`PolygonMinTimeContourSlow`): partly covered by `cool_min_layer_time`.

## Gaps
- Z-SEMIFLEX: no valid profile was produced by the headless extraction.
- Only the 0.4 mm nozzle exists in Z-Suite for the M200 Plus.

## Original M200 and M300 (Z-Suite 2.32)

`tools/gen_classic_presets.py` builds the `zortrax_m200` machine from Z-Suite 2.32's classic M200 configurations (0.4 mm nozzle, Standard infill, the 10 Zortrax filaments Z-Suite offers for it: 79 profiles in `plugins/ZortraxM/zsuite_profiles_m200/`). Layers are 0.09/0.14/0.19/0.29/0.39 mm (sliced at 0.10/0.15/0.20/0.30/0.39), quality types `z9` … `z39_normal`.

The material files are shared with the Plus printers, so every M200 value that depends on the filament goes in the M200's material-specific quality profiles, which outrank the material file; settings that are the same for all 79 profiles go in `definitions/zortrax_m200.def.json`. The classic keys differ from 3.7's: inner wall speed and flow come from `IV_Contour*`, retraction from `R_Back`, raft margin from `RS_ContourOffset`, support angle from `SB_Angle`, and first-layer speeds from `FL_*` (the classic M200 always prints on a raft). The first model layer on the raft also takes Z-Suite's first-layer flow: `material_flow_layer_0` / `skin_material_flow_layer_0` match `FL_InfillFeed` per `FL_InfillIncrement` spacing, and the wall `*_material_flow_layer_0` are `FL_ContourFeed` relative to the wall feeds (Cura multiplies them). Z-Suite deliberately starves this layer so the raft peels off; at full flow it fuses to the raft. Classic Z-Suite prints two walls. Fan: 20% for the first layers, then off for most filaments (autofan disabled), a fixed speed or Z-Suite's layer-time ramp where its profile enables autofan; the raft runs at 30%.

The same generator builds `zortrax_m300` from Z-Suite 2.32's M300 configurations: 7 Zortrax filaments (Z-ULTRAT, Z-GLASS, Z-HIPS, Z-PETG, Z-ESD, Z-PLA Pro, Z-ASA Pro; Z-Suite has no Z-ABS or Z-PCABS profiles for it), 54 profiles in `plugins/ZortraxM/zsuite_profiles_m300/`.

All 79 M200 and 54 M300 combinations were resolved in headless Cura and match the generator's values exactly.
